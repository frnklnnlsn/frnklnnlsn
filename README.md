## Projects

### 🐟 [Koi Idle](https://github.com/frnklnnlsn/koi-idle)
A koi pond idle game built in Godot 4. The fish are fully procedurally 
generated and animated — each one has a unique appearance, stats drawn from 
a rank-based bell curve distribution, and autonomous behavior driven by a 
component-based state machine. Fish bodies are simulated as inverse-kinematics 
chains with a travelling sine wave overlay. Idle economy with logistic growth 
curves, a save system, and a shop UI in progress.

`Godot` `GDScript` `GDShader` `procedural generation` `IK animation`

### 🎨 [KariNelsonArt](https://github.com/frnklnnlsn/KariNelsonArt)
A self-hosted artist portfolio website built for my mom. Static frontend 
generated by Hugo, backed by a custom Python/Flask admin panel for uploading 
and managing artwork without touching any code. The admin app writes to a 
SQLite database, exports a CSV, and triggers a Hugo rebuild automatically on 
every change. Includes a contact form with Gmail SMTP delivery.

`Python` `Flask` `Hugo` `SQLite` `self-hosted`
